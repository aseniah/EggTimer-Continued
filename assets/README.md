AI render via ChatGPT, 2026-09-07. The icon is built from this.
Prompt: WoW ability icon, a single speckled egg with a glowing golden crack leaking light and a faint arcane-blue shimmer, oil-painted, thick brushstrokes, dark blue-black vignette, square, no border or text.

`Icon.tga` (128x128) at the repo root is a `sips` crop and export of this file: `sips -c 1120 1120` then `-Z 128 -s format tga`.
